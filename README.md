# D.O.G.M.A.

*Dorn's Own G.A.M.M.A. Modification Anthology*

D.O.G.M.A. is a mod pack with over 50 features and fixes (made by me) which aim to enhance what makes G.A.M.M.A. great and improve what doesn't. It is also a list of mods (made by others) which do the same. You can pick and choose the mods/features you want to use.

See highlighted features on the [D.O.G.M.A. ModDB page](https://www.moddb.com/mods/stalker-anomaly/addons/dogma)
